
# Landon Hotel 

It's a hotel web application that allows users to reserve a room at the Landon Hotel web application. It was built with Angular on the frontend of the web application with a Java Spring Boot backend on the application while using a H2 database to store data internally. It's meant to resemble a hotel web application that allows users to visualize it using a simple demo service. 


## Demo

Link: www.thelandonhotelresort.com


## Run Locally

Clone the project

```bash
  git clone https://github.com/VkProjects907/Landon-Hotel-App.git
```

Go to the frontend project directory

```bash
  cd .\d387-advanced-java-master\src\main\UI\
```

Go to the backend project directory

```bash
  cd .\d387-advanced-java-master\
```

Install Angular dependencies

```bash
  npm install
```

Install Java Spring Boot dependencies

```bash
  mvn clean install
```

Start the frontend server

```bash
  ng serve
```

Start the backend server 
```bash
  mvn spring-boot:run
```
